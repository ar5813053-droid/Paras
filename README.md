Paras Clothe Emporium

**Your Style, Your Store.**

Complete Android e-commerce app for Paras Clothe Emporium — clothing & suit shopping.

## Stack

- **UI**: React 19 + TypeScript + Vite
- **Mobile**: Capacitor 7 (Android APK)
- **Backend**: Supabase (Auth, PostgreSQL, Storage, RLS)
- **Build**: GitHub Actions (no local Android Studio required)

## Phone-only development workflow

You develop on an Android phone:

1. Edit code via GitHub (web or app) or Termux
2. Push to GitHub
3. GitHub Actions builds the APK
4. Download the APK from the Actions run → Artifacts
5. Install on your phone

## Quick start (GitHub)

### 1. Create the repository

1. Go to [github.com/new](https://github.com/new)
2. Name it `paras-clothe-emporium` (or any name)
3. Create the repo (empty is fine)

### 2. Push this project

From Termux (or any git client):

```bash
cd /path/to/this/project
git init
git add .
git commit -m "Initial Paras Clothe Emporium demo"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/paras-clothe-emporium.git
git push -u origin main
```

### 3. (Optional) Add Supabase secrets

1. Create a free project at [supabase.com](https://supabase.com)
2. In GitHub repo → Settings → Secrets and variables → Actions
3. Add:
   - `VITE_SUPABASE_URL` = your project URL
   - `VITE_SUPABASE_ANON_KEY` = your anon/public key

The app builds and runs even without these (demo UI works offline with sample data).

### 4. Build the APK

1. Go to the **Actions** tab in your GitHub repo
2. Select **Build Android APK**
3. Click **Run workflow** → **Run workflow**
4. Wait ~8–15 minutes
5. When green, open the run → **Artifacts** → download `paras-clothe-emporium-debug-apk`
6. Unzip and install the `.apk` on your phone (enable Install from unknown sources)

### 5. After code changes

Just push to `main`. The workflow runs automatically. Or trigger it manually.

## Project structure

```
src/
  components/     # UI components & layout
  pages/
    customer/     # Storefront screens
    admin/        # Admin panel
    auth/         # Login / Signup
  lib/            # Supabase client, utils
  types/          # TypeScript types
  stores/         # Zustand stores (cart, auth)
android/          # Generated by Capacitor (on CI)
.github/workflows/android-apk.yml
```
